Frequently asked questions

Install aur setup se pehle in answers ko dekh lo.

Maya free hai?

Website ke current release ke mutabik APK free download hai. AI providers ki usage limits ya charges unki apni policies par depend kar sakte hain.

Kya Maya internet use karti hai?

AI chat, web search aur supported cloud features ke liye internet connection aur configured API keys ki zaroorat ho sakti hai.

Install kaise karun?

APK download karo, file open karo. Android agar permission maange to install unknown apps permission sirf us source ke liye allow karke install complete karo.

Kaun se permissions zaroori hain?

Microphone voice ke liye zaroori hai. Camera, notifications, contacts ya phone-related permissions sirf un features ke liye enable karo jo tum use karna chahte ho.
