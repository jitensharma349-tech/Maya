Maya: tumhari apni AI saathi

Hindi aur English me baat karti hai, camera se dekh kar batati hai, WhatsApp messages padh kar sunati hai aur tumhare chhote chhote kaam kar deti hai.

Maya download karo

Android 8.0 ya naya  •  Download free hai  •  Maya ek AI hai, insaan nahi

Maya kya kar sakti hai

Awaaz me baat

Bol kar poocho, Maya bol kar jawab degi. Hindi aur English dono.

Camera

Camera ya photo dikhao, Maya dekh kar batayegi.

WhatsApp padhna

Naye message kisne bheje, Maya sunayegi (notification access dene par).

Web khoj

Taaza jaankari ke liye internet par khoj sakti hai.

Phone aur Alarm

Number likh kar dialer kholo, alarm lagwao.

Yaaddasht

Tumhara naam, pasand aur notes yaad rakhti hai.

Install kaise karein

  1. Upar wala Maya download karo button dabao. File ka naam maya.apk hai.
  2. Download ke baad file kholo. Phone puchhe to "Is source se install karne do" (Install unknown apps) ko allow karo.
  3. Agar Play Protect chetawani de, to "More details" par dabao aur "Install anyway" chuno. Ye isliye aata hai kyunki Maya Play Store se nahi aa rahi.
  4. Install ho jaye to Maya kholo.
Apne bharose ki jagah se hi APK install karo. Ye file sirf isi website se download karo.

Pehli baar set up (3 step)

  1. Keys daalo. Maya ko dimaag aur awaaz ke liye free API keys chahiye: Groq (baat-cheet) aur Gemini (camera). App ke andar "Free key lo" button seedha sahi page khol deta hai.
  2. Phone use karne do. "Sab allow karo" dabao. Sirf microphone zaroori hai, baaki tum apni marzi se de sakte ho.
  3. Background me zinda rakho. Battery optimisation band karo, taaki screen off hone par bhi Maya chale.
Notification access ya Accessibility grey dikhe to: Settings → Apps → Maya → teen bindu (⋮) → "Allow restricted settings". Ye menu tab aata hai jab pehle un option par ek baar dabaya ho.

Privacy aur safety

  • Tumhari keys aur notes sirf tumhare phone ke app storage me rehti hain.
  • Jawab dene ke liye baat sirf tumhari chuni hui AI services (Groq, Gemini, ElevenLabs) ko bheji jaati hai.
  • Koi account ya login nahi chahiye.
  • Permissions tum jab chaho Settings se badal ya hata sakte ho.
